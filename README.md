# RPG-Server
---
## 서버 구조
파밍, 제작을 통해 강화 재료 수급 >> 재료로 강화를 해서 강해짐 >> 강한 보스를 잡음

### 사냥
- 필드 몬스터 사냥
- 이동기(직업마다 유/무의 차이)
- 반복 파밍

### 보스
- 레이드
- 1~4인 파티
- 기믹

### 내실
- 생산 시설
- 자동 채굴
- 제작 공장
- 강화 재료 제작

- 치명타 확률 적용
- 치명타 피해 적용
