# RPG-Server
---
## 서버 구조
사냥 + 내실 >> 보스 구조 순환

### 사냥
- 필드 몬스터 사냥
- 이동기(직업마다 유/무의 차이)
- 반복 파밍

### 보스
- 레이드
- 1~4인 파티
- 기믹

### 내실
- 생산 시설
- 자동 채굴
- 제작 공장
- 강화 재료 제작
